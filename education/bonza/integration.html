Web-services

Веб-сервис — приложение с уникальным URL и API.

Сервис-ориентированная архитектура (SOA) — подход с слабо связанными сервисами.

Клиент ↔ API ↔ Сервис
(REST, SOAP, JSON, XML)

Message broker

Посредник для снятия нагрузки с веб-сервисов.

Сущности: publisher (издатель) и consumer (потребитель).

Publisher → Exchange → Queue → Consumer

ESB

Шина данных на основе SOA.

Включает коннекторы, очередь сообщений, трансформацию данных.

Система A ↔ ESB ↔ Система B
↔ Система C ↔ ...

Data Layer

Подходит для импорта больших объемов данных.

Требуются ETL-процедуры (Extract, Transform, Load).
