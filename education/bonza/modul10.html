Что такое интеграция

Интеграция = объединение систем для обмена данными.

ЦФТ
CRM
ДБО
Процессинг
BI-отчеты

Цель: клиент видит актуальные данные везде — в офисе, интернет-банке, мобильном приложении.

Уровни интеграции

Бизнес-процессов → оформление кредита (CRM и ЦФТ)
Сервисов → API проверки баланса карты (CRM вызывает ЦФТ)
Данных → отчеты QlikView используют данные из ЦФТ и ДБО

Зачем нужна интеграция банку

Быстрая обработка заявок (кредит за 5 минут)
Снижение ошибок (данные клиента синхронизированы)
Единое окно для клиента (одна операция отражается везде)

Способы интеграции

Web-services (API) – проверка баланса карты
Message broker – гарантированная доставка транзакций с банкоматов
ESB (шина) – подключение CRM ↔ ЦФТ ↔ BI
Data Layer – выгрузка из ЦФТ в отчётность (ETL → QlikView)

Сравнение способов

Web-сервисы → быстрый доступ к данным
Message broker → надёжность при сбоях
ESB → гибкость для сложных проектов
Data Layer → отчётность и аналитика

Роль аналитика в интеграционном проекте

Выявляет системы, которые должны "общаться"
Определяет мастер-систему (например, ЦФТ для клиентов)
Описывает процессы обмена
Формирует ТЗ для разработчиков и тестировщиков

Навыки аналитика

🧠 Понимание архитектуры (что где хранится)
📝 Умение писать ТЗ на интеграции
📐 Знание нотаций (BPMN, DFD, ERD)
💬 Общение с заказчиками

Подготовка к сбору требований

1. Проанализировать документацию (ЦФТ, CRM)

2. Определить текущее состояние

3. Зафиксировать будущую картину:

Пример: клиент открывает счёт → автоматически появляется в ДБО

Классификация систем

Бизнес-данные → ЦФТ
Сервисные → CRM, ДБО
Процессные → интеграция кредитного процесса
Мониторинг → логирование интеграции

Блоки детализации интеграции

Процесс интеграции
Соответствие объектной модели (клиент в CRM ↔ клиент в ЦФТ)
Авторизация
Права доступа

Пример из банка

Кейс: клиент подал заявку на кредит в CRM
  1. CRM формирует заявку
  2. Интеграция отправляет её в ЦФТ
  3. ЦФТ создаёт продукт и возвращает номер договора
  4. CRM показывает клиенту статус

Журналирование интеграции

Логирование обменов между системами.

Пример: если платёж не дошёл из POS-терминала → брокер сообщений фиксирует ошибку.

Позволяет быстро находить и исправлять проблемы.

Описание объектов интеграции

Источник: ЦФТ
Приёмник: CRM
Поля: ИНН, ФИО, счёт
Правила перезаписи: мастер – ЦФТ

Постановка задач разработчикам (Jira)

Заголовок: «Интеграция ЦФТ и CRM по клиентам»
Описание: что передаём, зачем
Приложения: схема интеграции, маппинг полей

Пример задачи в Jira

Входящие параметры: ФИО, дата рождения
Исходящие: номер договора
Логирование: успех/ошибка
Ошибки: «Клиент не найден в ЦФТ»

Итог: зачем аналитик нужен в интеграции

Он связывает бизнес и ИТ.

Без аналитика: риск ошибок, дублирования данных, потеря времени.

С аналитиком: прозрачная интеграция, меньше ручной работы, довольные клиенты.
