🚀 VS Code для Vue.js: Настраиваем Рабочее Место

Готовимся к созданию крутых интерфейсов!

Настройка VS Code — это как подготовка кухни перед готовкой: всё станет быстрее, удобнее и без ошибок!

Аналогия: VS Code — твой верный помощник для создания сайтов на Vue.js!

📥 Шаг 1: Установка VS Code

Если VS Code ещё не установлен, давай сделаем это!

  • Перейди на code.visualstudio.com.
  • Нажми "Download" и выбери свою систему (Windows, macOS, Linux).
  • Запусти установщик и следуй инструкциям (обычно просто "Далее").
  • Открой VS Code — ты готов к следующему шагу!

🛠️ Шаг 2: Установка базовых расширений

Расширения — это как специи для готовки: добавляют новые функции!

Список расширений:

  • Volar: Главное расширение для Vue.js! Подсветка синтаксиса .vue-файлов, автодополнение, проверка ошибок.
  • Vue VSCode Snippets: Быстрые шаблоны кода (<template>, <script>).
  • Prettier: Форматирует код, чтобы он был аккуратным.

Как установить:

  • Открой VS Code.
  • Нажми на иконку "Extensions" (квадрат с 4 квадратиками).
  • Введи "Volar" в поиск и нажми "Install".
  • Повтори для "Vue VSCode Snippets" и "Prettier".

⚙️ Шаг 3: Настройка Vetur (для старых проектов)

Раньше для Vue.js использовали Vetur, но теперь Volar — стандарт. Они могут конфликтовать.

Инструкция:

  • Открой панель расширений в VS Code.
  • Поищи "Vetur". Если установлено, нажми "Disable" или "Uninstall".
  • Для новых проектов этот шаг не нужен — Volar всё сделает!

Аналогия: Это как убрать старую плиту, чтобы новая работала без сбоев.

🏗️ Шаг 4: Создание первого Vue-проекта

Мы используем Vite — быстрый инструмент для создания проектов.

Инструкция для Vite:

  • Убедись, что установлен Node.js (nodejs.org, проверь: node -v).
  • Открой терминал (в VS Code: "Terminal" → "New Terminal").
  • Перейди в папку: cd Desktop/my-vue-project.
  • Создай проект: npm create vue@latest.
  • Следуй подсказкам (имя проекта, TypeScript: нет, ESLint: да).
  • Перейди в папку: cd my-vue-project.
  • Установи зависимости: npm install.

Альтернатива (Vue CLI): npm install -g @vue/cli, затем vue create my-project.

Аналогия: Vite — как быстрый строитель, создающий каркас дома за секунды!

npm create vue@latest
cd my-vue-project
npm install

🌐 Шаг 5: Запуск проекта

Теперь запустим проект и увидим его в браузере!

Инструкция:

  • В терминале убедись, что ты в папке проекта: cd my-vue-project.
  • Запусти сервер: npm run dev.
  • Открой в браузере ссылку (обычно http://localhost:5173).
  • Увидишь стартовую страницу Vue!
