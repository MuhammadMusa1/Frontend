Основы Java

Java — объектно-ориентированный язык программирования с сильной типизацией. Основные типы данных: примитивные (int, double, boolean) и ссылочные (String, массивы).

Переменные и типы данных

  • Примитивные типы: byte, short, int, long, float, double, char, boolean.
  • Ссылочные типы: Классы, интерфейсы, массивы.
// Пример объявления переменных
int age = 25;
double salary = 1500.50;
String name = "Alice";
boolean isActive = true;

Пример: Используйте int для целых чисел в диапазоне -2^31 до 2^31-1.

Операторы

Арифметические: +, -, *, /, %. Логические: &&, ||, !. Сравнения: ==, !=, >, <, >=, <=.

// Пример операторов
int a = 10;
int b = 20;
boolean result = (a < b) && (b % 2 == 0);

Условные конструкции

if-else, switch-case.

if (age >= 18) {
    System.out.println("Взрослый");
} else {
    System.out.println("Ребенок");
}

Циклы

for, while, do-while, foreach.

for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

Объектно-ориентированное программирование (ООП)

Основные принципы: инкапсуляция, наследование, полиморфизм, абстракция.

Классы и объекты

class Person {
    String name;
    int age;
    
    void greet() {
        System.out.println("Привет, " + name);
    }
}

// Создание объекта
Person p = new Person();
p.name = "Bob";
p.greet();

Наследование

Классы могут наследовать от других с помощью extends.

class Employee extends Person {
    double salary;
}

Интерфейсы

Определяют контракт с помощью implements.

interface Printable {
    void print();
}

class Book implements Printable {
    public void print() {
        System.out.println("Печать книги");
    }
}

Абстрактные классы

abstract class Shape {
    abstract double area();
}

Коллекции

Java Collections Framework: List, Set, Map, Queue.

ArrayList

Динамический массив.

import java.util.ArrayList;

ArrayList list = new ArrayList<>();
list.add("Apple");
list.add("Banana");
System.out.println(list.get(0)); // Apple

HashSet

Множество без дубликатов.

import java.util.HashSet;

HashSet set = new HashSet<>();
set.add(1);
set.add(2);

HashMap

Ключ-значение.

import java.util.HashMap;

HashMap map = new HashMap<>();
map.put("Age", 30);
System.out.println(map.get("Age")); // 30

Исключения

Обработка ошибок с try-catch-finally, throws.

Базовый пример

try {
    int x = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Деление на ноль!");
} finally {
    System.out.println("Завершение");
}

Пользовательские исключения

class MyException extends Exception {
    MyException(String msg) {
        super(msg);
    }
}

Ввод/Вывод (I/O)

Работа с файлами, потоками.

Чтение файла

import java.io.*;

try (BufferedReader br = new BufferedReader(new FileReader("file.txt"))) {
    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
} catch (IOException e) {
    e.printStackTrace();
}

Запись в файл

try (BufferedWriter bw = new BufferedWriter(new FileWriter("file.txt"))) {
    bw.write("Hello, Java!");
} catch (IOException e) {
    e.printStackTrace();
}

Потоки (Multithreading)

Параллельное выполнение с Thread и Runnable.

Создание потока

class MyThread extends Thread {
    public void run() {
        System.out.println("Поток запущен");
    }
}

MyThread t = new MyThread();
t.start();

Синхронизация

synchronized void method() {
    // Критическая секция
}

Лямбды и Stream API

Функциональное программирование с Java 8+.

Лямбда-выражения

(int a, int b) -> a + b;

Stream API

import java.util.*;
import java.util.stream.*;

List numbers = Arrays.asList(1, 2, 3, 4);
numbers.stream()
    .filter(n -> n % 2 == 0)
    .map(n -> n * 2)
    .forEach(System.out::println); // 4, 8

Дженерики (Generics)

Позволяют создавать классы, интерфейсы и методы с параметрами типов для type-safety.

Базовый пример класса

class Box {
    private T value;
    
    public void set(T value) {
        this.value = value;
    }
    
    public T get() {
        return value;
    }
}

Box intBox = new Box<>();
intBox.set(10);

Ограничения типов

Используйте extends для upper bound.

class NumberBox {
    // ...
}

Wildcards

void printList(List list) {
    for (Object elem : list) {
        System.out.println(elem);
    }
}

Аннотации (Annotations)

Метаданные для кода, используемые для конфигурации, валидации и т.д.

Встроенные аннотации

  • @Override: Переопределение метода.
  • @Deprecated: Устаревший код.
  • @SuppressWarnings: Подавление предупреждений.
@Override
public String toString() {
    return "Переопределенный toString";
}

Пользовательские аннотации

import java.lang.annotation.*;

@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@interface MyAnnotation {
    String value();
}

class MyClass {
    @MyAnnotation("Test")
    public void method() {}
}

Перечисления (Enums)

Специальный тип класса для фиксированного набора констант.

Простой enum

enum Day {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}

Day today = Day.MONDAY;

Enum с полями и методами

enum Planet {
    MERCURY (3.303e+23, 2.4397e6),
    VENUS   (4.869e+24, 6.0518e6);
    
    private final double mass;   // in kilograms
    private final double radius; // in meters
    
    Planet(double mass, double radius) {
        this.mass = mass;
        this.radius = radius;
    }
    
    public double surfaceGravity() {
        return 6.67300E-11 * mass / (radius * radius);
    }
}
