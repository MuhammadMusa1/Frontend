 Генератор Мемов

Веб-приложение для создания мемов с возможностью загрузки изображений и добавления текста.

 Функциональность

-  Загрузка пользовательских изображений
-  Добавление верхнего и нижнего текста
-  Предпросмотр в реальном времени
-  Скачивание готовых мемов
-  Готовые примеры для быстрого старта
-  Адаптивный дизайн

 Технологии

- **HTML5 Canvas** - отрисовка мемов
- **Vanilla JavaScript** - логика приложения
- **CSS3** - стилизация и анимации
- **File API** - работа с файлами

 Структура проекта
meme-generator/
├── index.html # Главная страница
├── styles.css # Стили и анимации
├── script.js # Логика приложения
└── README.md # Документация

##  Использование

1. **Выберите изображение** - нажмите "Выбрать изображение"
2. **Добавьте текст** - введите верхний и нижний текст
3. **Сгенерируйте** - мем создается автоматически
4. **Скачайте** - нажмите "Скачать мем"

##  Особенности

- Стиль текста в духе классических мемов (Impact font)
- Тени и обводка для лучшей читаемости
- Автоматическая подгонка размера текста
- Поддержка разных форматов изображений
- Полная адаптивность для мобильных устройств
