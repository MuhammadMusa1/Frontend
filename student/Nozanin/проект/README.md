 Meme Generator - Документация
 О проекте

Веб-приложение для создания мемов с возможностью загрузки изображений и добавления текста.
 Технологии

    HTML5 Canvas - генерация изображений

    Vanilla JavaScript - логика приложения

    CSS3 - стилизация и анимации

    File API - работа с файлами

 Функциональность

     Загрузка пользовательских изображений

     Добавление верхнего и нижнего текста

     Предпросмотр мема в реальном времени

     Скачивание готового мема

     Адаптивный дизайн

 Особенности

    Стиль текста в стиле классических мемов (Impact font)

    Тени и обводка для лучшей читаемости

    Градиентный фон и современный UI

    Поддержка разных размеров изображений

 Оценка: 8.0/10

Сильные стороны:

    Практичная и востребованная функциональность

    Качественная работа с Canvas

    Хороший пользовательский опыт

    Чистый и понятный код
