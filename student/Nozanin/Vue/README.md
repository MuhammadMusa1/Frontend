 Архитектура Vue.js
Composition API:
javascript

setup() {
  const newTodo = ref('');           // Реактивная переменная
  const todos = ref([]);             // Реактивный массив
  
  // Жизненный цикл
  onMounted(() => { /* ... */ });
  
  // Watch эффект
  watch(todos, (val) => { /* ... */ }, { deep: true });
  
  return { newTodo, todos, addTodo, toggleComplete, deleteTodo };
}

Реактивность:

    ref() для примитивов и объектов

    watch() для отслеживания изменений

    Автоматическое обновление DOM

const stats = computed(() => {
  const total = todos.value.length;
  const completed = todos.value.filter(t => t.completed).length;
  return { total, completed, active: total - completed };
});
